# 📊 Data Analyst Internship – Task 2
## Data Visualization and Storytelling using Tableau

### Project Overview
This project analyzes the Sample Superstore dataset using Tableau Public. It explores sales performance, monthly trends, product categories, and regional profitability through charts and a dashboard.

### Objectives
- Analyze sales and profit data.
- Identify top-performing product categories.
- Understand monthly sales trends.
- Compare regional performance.
- Present business insights through visualizations.

### Tools Used
- Tableau Public (Online)
- CSV dataset
- GitHub

### Dataset
**Dataset:** Sample Superstore

The dataset includes order dates, product categories, sub-categories, sales, profit, quantity, discount, region, and customer information.

### Visualizations Created

1. **Sales by Category – Bar Chart**  
   Compares sales across Furniture, Office Supplies, and Technology.

2. **Monthly Sales Trend – Line Chart**  
   Shows how sales change over time.

3. **Profit by Region – Bar Chart**  
   Compares profit across geographical regions.

4. **Sales by Sub-Category – Horizontal Bar Chart**  
   Highlights the highest- and lowest-selling sub-categories.
